## What this repository is for

- **Bug reports**: something does not work, crashes, renders wrong, or behaves differently from the Java Edition.
- **Feature requests**: ideas and suggestions.
- **Progress updates**: development status is posted in the pinned *Progress updates* issue.

This repository contains no source code, no game files and no downloads.
Gaius does not provide builds, and nobody may offer or ask for them here.
Never post game files, builds, decompiled game code or links to any of them.
Read the [issue rules](CONTRIBUTING.md) before you post.

## Reporting a bug

Use the **Bug report** form and include the browser and version, the Minecraft
profile (26.3 / 26.2 / 1.21.11), whether you use the site or the single-file
page, the graphics backend shown in the debug screen (WebGPU / WebGL2), steps
to reproduce, and a screenshot or the browser console log if possible.
