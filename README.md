# Gaius-Client

Gaius Issue Tracker ONLY, No source code or release will be provided

https://dsc.gg/gaius

## What this repository is for

- **Bug reports** — something does not work, crashes, renders wrong, or behaves differently from the Java Edition.
- **Feature requests** — ideas and suggestions.
- **Progress updates** — development status is posted in the pinned *Progress updates* issue.

This repository contains no source code, no game files and no downloads. Please do not attach game files, builds or links to them in issues.

## 本仓库用途

- **问题反馈**：无法运行、崩溃、画面错误，或与 Java 版行为不一致。
- **功能建议**。
- **开发进度**：发布在置顶的 *Progress updates* issue 中。

本仓库不包含源代码、游戏文件或下载。请不要在 issue 中附带游戏文件、构建产物或相关链接。

## Reporting a bug

Use the **Bug report** template and include the browser and version, the Minecraft profile (26.3 / 26.2 / 1.21.11), whether you use the site or the single-file page, the graphics backend shown in the debug screen (WebGPU / WebGL2), steps to reproduce, and a screenshot or the browser console log if possible.
